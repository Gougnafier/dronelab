# NVIDIA Claw Agent Challenge 2026

Dépôt de départ pour une nouvelle idée d’agent. **Aucune direction de produit, architecture, stack ou démonstration n’est choisie.**

Le projet repart de zéro après l’exploration de deux pistes conservées dans des dépôts voisins : `../Nvidia_Claw_Agent_Challenge:Paris/` (3D) et `../Nvidia_Claw_Radio/` (radio). Leurs résultats peuvent servir de contexte, mais aucun code ou choix technique n’est repris ici par défaut.

Le seul cadre initial est le [brief du challenge](docs/challenge.md) fourni par le porteur du projet : construire un agent qui mène une tâche réelle dans la durée sans surveillance à chaque étape. La prochaine étape est de définir le problème à résoudre et une démonstration vérifiable.

Voir les [consignes de travail](AGENTS.md), le [cadrage ouvert](docs/project.md), les [décisions](docs/decisions.md) et le [suivi](docs/kanban.md).
