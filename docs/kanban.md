## K00 — Dépôt neuf

- Dépôt Git local distinct ; cadre du challenge et consignes ; aucune implémentation ni stack reprise.
- Vérifier l’état Git propre, les liens documentaires et l’exclusion des secrets.

## K01 — Direction à choisir

- Décrire une tâche réelle exécutée dans la durée, le public aidé et la valeur produite.
- Définir une expérience qui peut échouer et une vidéo de démonstration fidèle à ce qui fonctionne.
- Consigner ensuite la direction décidée dans `docs/decisions.md`.
